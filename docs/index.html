📱 应用层

面向用户的功能模块：跟随、抓取、导航、SLAM、YOLO、语音。每个 demo 通过 onekey.sh 调用。

⚙️ 核心层

统一底座 driver_bringup、URDF 模型、公共参数定义、消息接口。所有应用 launch 的必经之路。

🔌 驱动层

硬件抽象：底盘串口驱动 (C++)、相机自动检测、雷达自动检测、机械臂控制。

启动调用链

onekey.sh (设定 CAMERATYPE / LIDARTYPE / ARMTYPE) └─ 应用 launch (如 teleop.launch.py) └─ driver_bringup.launch.py ← 统一底座 ├─ spark_description.launch.py (URDF 模型) ├─ spark_base.launch.py (底盘驱动) ├─ start_camera.launch.py (相机自动检测) │ └─ d435.launch.py / astra*.launch.py └─ start_lidar.launch.py (雷达自动检测) └─ ydlidar_g6.launch.py / ydlidar_g2.launch.py
  • 所有应用 launch 都通过 driver_bringup 启动驱动层
  • driver_bringup 4 个子 launch 并行启动
  • 相机/雷达类型由 lsusb + /opt/lidar.txt 自动检测

设计决策

common_launch_args.py

15 个应用 launch 文件共享 5 个参数声明，避免逐一修改：camera_type_tel、lidar_type_tel、enable_arm_tel、arm_type_tel、namespace。

PushRosNamespace 使用规范

  • 只在 driver_bringup.launch.py 中使用 PushRosNamespace 包裹子 launch
  • 子层（start_camera、d435、start_lidar、ydlidar_g6）不再重复包裹
  • nav2_bringup.launch.py 独立使用

新增一个 Demo

Step 1: 创建应用包

cd src/spark_app
ros2 pkg create --build-type ament_python spark_my_demo \
  --dependencies rclpy std_msgs sensor_msgs geometry_msgs

Step 2: 写应用 launch 文件

创建 spark_my_demo/launch/my_demo.launch.py：

from spark_bringup.common_launch_args import declare_common_arguments

def generate_launch_description():
    # 1. 声明公共参数（必须！）
    declared_arguments = declare_common_arguments()

    # 2. 引用参数
    namespace = LaunchConfiguration('namespace')

    # 3. 启动驱动（必须！）
    driver_launch = IncludeLaunchDescription(
        PythonLaunchDescriptionSource(
            os.path.join(spark_bringup_dir, 'launch', 'driver_bringup.launch.py')),
        launch_arguments={
            'camera_type_tel': camera_type_tel,
            'lidar_type_tel': lidar_type_tel,
            'namespace': namespace,      # ← 必须传递
        }.items())

    # 4. 启动自己的节点
    my_node = Node(
        package='spark_my_demo',
        executable='my_node',
        namespace=namespace,             # ← 必须加上
        output='screen')

    return LaunchDescription(declared_arguments + [driver_launch, my_node])

Step 3: 注册到 onekey.sh

# 在菜单中添加（约 657 行）
echo "  ${Green_font_prefix} 11.${Font_color_suffix} 我的新 Demo"

# 在 case 分支添加（约 700 行）
11) my_demo_function ;;

# 添加函数
my_demo_function(){
    PROJECTPATH=$(cd `dirname $0`; pwd)
    source ${PROJECTPATH}/install/setup.bash
    ros2 launch spark_my_demo my_demo.launch.py \
        camera_type_tel:=${CAMERATYPE} \
        lidar_type_tel:=${LIDARTYPE}
}

修改 Launch 文件注意事项

✅ 必须 import

所有应用 launch 必须 from spark_bringup.common_launch_args import declare_common_arguments

✅ 必须传 namespace

给 driver_bringup 和自己 Node 都要传 namespace=namespace

🚫 禁止重复 PushRosNamespace

子层 launch（start_camera、d435、start_lidar、ydlidar_g6）不要再用 PushRosNamespace

🚫 修改后必须做的事

全量编译 37/37 → git push → 真机测试（涉底盘运动先确认）
