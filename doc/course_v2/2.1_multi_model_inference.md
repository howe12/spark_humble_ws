# 2.1 垃圾分类多模型实时推理（Random Forest / XGBoost / SVM）

## 概述

在决策树版本的基础上，新增了 **随机森林**、**XGBoost**、**SVM** 三种模型的实时推理节点。四个节点可同时运行、互不干扰——各自订阅同一相机话题，发布到不同的结果话题。

所有节点均已迁移到 ROS2 (`rclpy`)，不再依赖 ROS1 (`rospy`)。

## 四节点对比

### 节点名与话题

| 节点 | 可执行名 | 节点名 | 发布话题 | 置信度话题 |
|------|---------|--------|---------|-----------|
| 决策树 | `waste_classifier` | `waste_classifier_dt` | `/waste_classification` | `/waste_classification/confidence` |
| 随机森林 | `waste_classifier_rf` | `waste_classifier_rf` | `/waste_classification_rf` | `/waste_classification_rf/confidence` |
| XGBoost | `waste_classifier_xgb` | `waste_classifier_xgb` | `/waste_classification_xgb` | `/waste_classification_xgb/confidence` |
| SVM | `waste_classifier_svm` | `waste_classifier_svm` | `/waste_classification_svm` | `/waste_classification_svm/confidence` |

> 每个节点发布到专属话题，四个同时运行不冲突。

### 模型加载方式

决策树 / 随机森林 / SVM 都继承自 sklearn，统一用 `joblib`：

```python
import joblib
model = joblib.load('waste_classifier.pkl')
```

XGBoost 底层是 C++ 实现，不能用 pickle 序列化，必须用原生 API：

```python
from xgboost import XGBClassifier
model = XGBClassifier()
model.load_model('waste_xgboost.json')
```

SVM 额外需要 StandardScaler（特征标准化），推理时必须加载训练时的 scaler：

```python
model = joblib.load('waste_svm.pkl')
scaler = joblib.load('waste_scaler.pkl')
features = scaler.transform([raw_features])
prediction = model.predict(features)
```

## 节点架构

所有四个节点遵循相同的流水线结构：

```
相机话题 (/camera/color/image_raw)
        │
        ▼
  CvBridge: Image → cv2 Mat (BGR)
        │
        ▼
  cv2.resize → 200×200
        │
        ▼
  特征提取 (12维)
  ├── 几何特征 (5): aspect_ratio, extent, circularity, rectangularity, complexity
  ├── 颜色特征 (5): mean_hue, mean_saturation, white_ratio, highlight_ratio, color_consistency
  └── 纹理特征 (2): texture_entropy, texture_contrast (向量化 GLCM)
        │
        ▼
  模型预测 → class_name + confidence
        │
        ▼
  发布结果: /waste_classification_xx (String)
  发布置信度: /waste_classification_xx/confidence (Float32)
```

## 使用方法

### 启动推理节点

```bash

ros2 run ml_basics waste_classifier_rf

ros2 run ml_basics waste_classifier_rf --ros-args -p image_topic:=/camera/rgb/image_raw

# 四节点同时运行（不同终端）
ros2 run ml_basics waste_classifier &

```

## 与 ROS1 参考版的差异

| 项目 | ROS1 参考版 | ROS2 实践版 |
|------|-----------|-----------|
| Python API | `rospy` | `rclpy` |
| 节点初始化 | `rospy.init_node()` | `Node.__init__()` |
| 话题发布 | `rospy.Publisher()` | `self.create_publisher()` |
| 话题订阅 | `rospy.Subscriber()` | `self.create_subscription()` |
| 参数获取 | `rospy.get_param('~name')` | `self.declare_parameter()` + `self.get_parameter()` |
| 模型路径 | 硬编码 `~/scorpio/...` | `__file__` 相对路径 → `../models/` |
| 特征提取 | 简单阈值分割 + Python for 循环 GLCM | 自适应阈值 + 向量化 numpy GLCM |
| 话题隔离 | 同名发布易冲突 | 四模型专属话题 |

## 特征提取关键代码

12 维特征提取器对所有四个节点通用，采用**向量化 GLCM** 替代参考版中的 Python 逐像素循环，推理速度显著提升：

```python
def extract_features(self, image):
    gray = cv2.cvtColor(image, cv2.COLOR_BGR2GRAY)
    hsv = cv2.cvtColor(image, cv2.COLOR_BGR2HSV)

    # 自适应阈值 → 形态学处理 → 最大轮廓
    thresh = cv2.adaptiveThreshold(gray, 255,
        cv2.ADAPTIVE_THRESH_GAUSSIAN_C, cv2.THRESH_BINARY_INV, 11, 2)
    kernel = np.ones((3, 3), np.uint8)
    thresh = cv2.morphologyEx(thresh, cv2.MORPH_CLOSE, kernel)
    contour = max(contours, key=cv2.contourArea)

    # 5 几何 + 5 颜色 + 2 纹理 = 12 维

```

## 模型训练与导出

训练脚本 `waste_train_tree.py` 目前输出决策树模型。RF/XGB/SVM 的训练需新增对应脚本，模型导出方式各有不同：

```python
# sklearn 系 (RF / SVM) — joblib.dump
import joblib
joblib.dump(rf_model, 'models/waste_random_forest.pkl')

# SVM 额外导出 StandardScaler
joblib.dump(scaler, 'models/waste_scaler.pkl')

# XGBoost — 原生 save_model（输出 JSON）
xgb_model.save_model('models/waste_xgboost.json')
```
